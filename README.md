# Mark My Words — a VRG app

Six dials per person (friendly, tech savvy, busy, hierarchy, handholding, delegation) on a radar
you drag, plus a note. It turns them into a short brief, so you, or your AI, write to each person
the way they like to be written to.

Local-first: no sign-in, no server, no telemetry. Your data stays in your browser and in a JSON
file you export and own.

**Status: v0.1 is out.**

- **Try it:** https://vrgli.github.io/mark-my-words/
- **Download:** the zip on the [Releases](https://github.com/vrgli/mark-my-words/releases) page

## Use it

Open `index.html` in a browser, or use the link above. That is all. Nothing to install, nothing
to build. Add a person, drag the yellow dots on the radar (or use the sliders), and copy the brief
for your AI. **Export JSON** saves everyone to a file; **Import JSON** brings them back.
