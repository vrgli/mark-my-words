# Mark My Words — a VRG app

Six dials per person (friendly, tech savvy, busy, hierarchy, handholding, delegation) on a
radar you drag, plus a note. So you, or your AI, write to each person the way they like to be
written to. Local-first, no sign-in, your data stays in a JSON file you own.

**Status: in the works.** The public version is not built yet and there is no download yet.
When it is ready, the source lands here and the zip goes on the
[Releases](https://github.com/vrgli/mark-my-words/releases) page.

## Fork it

Once the source is here: click **Fork** at the top of this page, clone your fork and open
`index.html` in a browser. Vanilla JS, zero dependencies, nothing to build. No account, no
server, no telemetry.
